## Inactive steps are never resolved

A step may carry an `if` shell condition, and a false condition skipped the step when applying. Its includes were still resolved on the way there: `lint`, the file lookup `up` runs for every pending file, `rebase`, and `reconcile` walked every step and cloned every git include. A `migrate.yml` with a claimius step behind `if: '[ "$CONNECT_MODE" != "standalone" ]'` failed a standalone `up` with `git clone ... authentication required` when no token was set, before a single file ran.

Every command now checks the condition before it resolves a step, the same way preflight and the requirement scan already did. A false step is never fetched, never linted, never applied, and never part of a reconcile candidate. `rebase --prune` leaves the ledger rows of an inactive step alone, so an applied debug seed is not folded on a run where its condition is false.
